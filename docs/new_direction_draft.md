# Wayfarer's Wake — Unreal Engine Direction

## Core idea

A **single-player hunting, survival, and exploration game** set in a **huge procedurally generated fantasy wilderness**. Think *Prologue: Go Wayback!* meets *theHunter: Call of the Wild*, with lighter survival and a touch of homesteading.

## Priorities

* **Hunting first:** wildlife, tracking, stalking, and harvesting. Include ordinary animals and some fantasy creatures.
* **Exploration:** vast forests, mountains, rivers, lakes, coasts, and islands. The wilderness itself should be worth exploring.
* **Simple survival:** food, water, weather, shelter, and basic crafting/building. Challenging, but not unnecessarily complicated. (few basic crafting stations like workbench, forge, cooking station). Skills and crafting skills/recipes learned by doing things from that category. 
* **Sailing and fishing:** small boats for exploration, with sea life ranging from peaceful creatures to occasional dangers. This part is quite important. Sailing has to be immersive to a point realistic but not overcomplicated. Best reference would be Valheim, Sea of Thieves and Windrose. That's why ocean/lake simulations are important. Fishing with a rod and big sea monster hunting that is a big challenge. 
* **Home life:** building from gathered materials (walls of different types, doorframes, windows, roofs) best reference would be Valheim, a little farming, animal husbandry, and pets or hunting companions, taming.
* **Simple points of interest:** occasional cabins, hunter's watchtowers, campsites, caves, ruins, and docks, placed sensibly by the world generator. No complex NPC systems required.

## Scope

**Keep it focused.** No multiplayer for now, no simulated settlements, economies, or elaborate town/village generation (like it was planned for Thornwake). Those bigger living-world ideas stay with the **Godot branch**.
For Unreal, prioritize a believable, beautiful, enjoyable wilderness and a satisfying loop: **explore → track → hunt → survive → return home → venture farther**. A large world does not need to be packed with content; quiet, empty spaces are part of the experience.
